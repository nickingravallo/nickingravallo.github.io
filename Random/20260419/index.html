TurboFire v0.1

Incredibly unfortunate timing for a RAM crisis

April 20, 2026

TurboFire is a game-theory-optimal poker solver that has been in development since the end of 2025, with serious development beginning in early 2026. A poker solver's goal, and thus TurboFire's goal, is to generate an optimal response to an opponents action, finding the 'correct' way to play any hand on any given board. Although this technology can be used for bots, it is mainly utilized in hand analysis and as a study tool for professionals. TurboFire, in its current state, is not ready for real-world use. Solving a complete game tree requires a machine with 512GB of ram at the minimum.

Why is TurboFire so memory-intensive?

In short, TurboFire currently has no memory optimizations to thin down the game tree, outside of low hanging fruit such as using int8_t for the active player and betting action, and using uint16_t for betting sizes. Each hand combination represented inside of TurboFire utilizes around ~200MB, with a range distribution of 1326*2 possible hands being represented in a full tree. In a reasonable situation, such as a 3! pot 6max between the BTN and UTG+1, the game tree will only require ~50GB of memory. There are several improvements that can be made, including isomorphic runouts and quantizing regret and strategy values.
